# Miris for Adobe Substance 3D Painter

Installers for the Miris publish plugin for Adobe Substance 3D Painter. Each
release carries a signed and notarized macOS package, a Windows installer, a
plugin ZIP, and a `release-manifest.json` with SHA-256 digests.

**[Download the latest release](https://github.com/Miris-Inc/miris-substance-painter/releases/latest)**

- macOS: `miris-substance-painter-<version>.pkg`
- Windows: `miris-substance-painter-<version>.exe`

Install instructions are in [INSTALL.md](INSTALL.md), which also ships inside
the package.

## Source

[`miris/`](miris) is the plugin from the release ZIP. Each new release tag points
to the commit holding that version's source.

You are welcome to fork, clone, and experiment with the source. We don't accept
pull requests.

Report bugs through [GitHub issues](https://github.com/Miris-Inc/miris-substance-painter/issues).
For anything else, contact [support@miris.com](mailto:support@miris.com).
