# Miris for Adobe Substance 3D Painter

The Miris publish plugin for Adobe Substance 3D Painter: its source code, and
installers for every release.

**[Download the latest release](https://github.com/Miris-Inc/miris-substance-painter/releases/latest)**

- macOS: `miris-substance-painter-<version>.pkg` (signed and notarized)
- Windows: `miris-substance-painter-<version>.exe`

Each release also carries a ZIP of the plugin and a `release-manifest.json`
listing the SHA-256 digest of every file. Install instructions are in
[INSTALL.md](INSTALL.md), which also ships inside the package.

## Source

The [`miris/`](miris) folder is the plugin exactly as it ships in the latest
release. You're welcome to fork, clone and experiment with it.
